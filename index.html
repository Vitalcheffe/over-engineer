003 / COLORWAYS

Eight accents. One rule per page.

A colorway swaps exactly one CSS variable: --accent. It is carried by the filet-top on card hover, the reading progress bar, the eyebrow dot, the stat-value, and the project-rule on hover. Never two saturated colors on the same page.

004 / PRINCIPLES

Eight named rules. Read before editing.

The system is enforced by named design rules — the same discipline archify uses. Each rule kills a specific failure mode that would otherwise drag the work into generic-SaaS territory.

Vibe Parity
The Sibling Rule
Same vibe ⇒ same typography, motion, composition. Two sites with the same vibe must look like siblings at first glance. The over-engineer portfolio (navy) and the raindrops project page (sky) share field-journal DNA — different accent, same skeleton.
Colorway Identity
The One-Accent Rule
Colorway is an accent, not a theme. amber doesn't mean "traffic" — it means "the accent color of this project is amber". Semantic meaning comes from content, never from color.
Flat at Rest
The Anti-SaaS Rule
No shadows by default. Borders + tone define structure. A card at rest is border + tonal fill, never elevation. This single rule kills 80% of the generic-SaaS look.
Motion Budget
The Three-Signature Rule
A page gets exactly three motion signatures: reveal on scroll, card hover, one vibe-specific atmosphere. No marquee, no count-up spam, no shimmer, no parallax everywhere. Reduced motion disables all three.
One Display
The Single Family Rule
One display family. One body family. One mono family. Weight and style swaps are allowed; additional font families are forbidden. Hierarchy comes from weight + scale + spacing, not from decorative faces.
No-Gradient
The Anti-Trend Rule
Gradients are forbidden except in two cases: (1) one radial-subtle behind the hero as atmosphere, (2) progress bars. No gradient text, no gradient buttons, no gradient cards. Trends age badly; restraint doesn't.
Density
The Weight Contrast Rule
Body text is 300-400 weight. Mono labels are 500-700. Display is 700-800. Contrast comes from weight, not color. This is why the body is muted but the labels cut.
Anti-Cliché
The Forbidden List
Banned: glassmorphism, gradient text, icon-pack floating, "Trusted by" logo rows, 3-card equal-height features, hero with isometric illustration, emoji as icons, "Get started" CTAs. Each one is a tell.

006 / BUILD

One command. One HTML file.

The build script reads a content JSON, picks a vibe + colorway + theme, and emits a single self-contained HTML file (~50-80kb) with all CSS inlined. Ship anywhere — GitHub Pages, Netlify, S3. No build step at runtime, no JS framework, no dependencies.

$ node scripts/build.mjs \ content/<name>.json \ <vibe> \ <colorway> \ <theme> \ <out.html> # Example: render the over-engineer portfolio $ node scripts/build.mjs \ content/over-engineer.json \ field-journal \ navy \ dark \ download/over-engineer/index.html # → Built: download/over-engineer/index.html # → vibe=field-journal colorway=navy theme=dark # → size=76.4kb
