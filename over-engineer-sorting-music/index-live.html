012 / SORTING-MUSIC

The algorithm is the song.

Sort an array of numbers. Listen. Each comparison plays a note. The algorithm's structure becomes audible.

Bubble sort: a slow ascending arpeggio. Each pass nudges the largest remaining element to the end. The pattern is regular, almost meditative. Insertion sort: a stuttering walk, each new element probes leftward. Selection sort: clean staccato — find min, swap, find next min.

Quick sort is chaos. Merge sort is harmony. The algorithm is the song.

Spectral analysis confirms the intuition. Quick sort's audio has high spectral entropy (broadband noise) because of its randomized pivot choices. Merge sort has distinct harmonic peaks because of its recursive structure (log₂N levels, each with 2^k parallel comparisons). Bubble sort has a single dominant frequency (1/(N-1) of the playback rate) because every pass is identical.

Sonification Pipeline
Mapping: array value → MIDI pitch (60-96, 4 octaves). Comparison → note (80ms duration, velocity 80). Render via fluidsynth piano. Each algorithm produces a 30-second WAV for N=64.

SPECTRAL
FFT Analysis
Method: FFT of each WAV (44100 Hz, 4096-point Hann window). Spectral entropy = -Σp·log(p) over normalized frequency bins. Higher entropy = more chaotic.

003 / METHODOLOGY

How the project is structured.

Every Over Engineer project follows the same six-step pipeline: observe, model, simulate, optimize, visualize, document. Sorting Algorithms as Music was observed in the wild. The model is Sonification: map each array comparison to a MIDI note. Pitch ∝ array value. Duration ∝ comparison count. Spectral analy.

Visualization is the project's deliverable: a 60-second animation showing the model in action, with the key metric (Quick sort: high entropy · Merge sort: harmonic) overlaid as a corner readout. The transition is visible, the result is reproducible.

The documentation is honest. Subjective — sonification is an art as much as science. Audio quality depends on synth (used fluidsynth piano). Spectral analysis limited to FFT (could use wavelet for time-frequency). No formal listening test — just my ... The point is not to replace professional tools — it's to show that the everyday phenomenon is, in fact, a known mathematical object with known solutions.
